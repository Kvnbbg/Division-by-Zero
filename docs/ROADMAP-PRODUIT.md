# Feuille de route produit — TDAAH

**Nom :** TDAAH (Division by Zero)
**Promesse :** appareil de mesure métrique et conversion, prévisible, attribuable.
**Canaux :** web TDAAH · agent Spring Boot · CLI Python · streams Kvnbbg Creations

## Vision en trois horizons

### Horizon 1 — Outil fiable (maintenant)
L’utilisateur convertit et calcule sans surprise. La division par zéro est nommée. L’interface porte le filigrane Kevin Marville / Tech & Stream.

### Horizon 2 — Agent de mesure
Un service Spring Boot exécute les mêmes règles, historise, et peut être interrogé en langage naturel uniquement via des outils validés.

### Horizon 3 — Atelier connecté
TDAAH devient le module de grandeur d’un atelier plus large, sans absorber la musique ni les NFT dans le runtime de calcul.

## Ce que TDAAH n’est pas

- Une place de marché NFT.
- Un lecteur qui remplace kvnbbg-creations.io.
- Un clone visuel de techandstream.com.

L’agent calcule des grandeurs ; il ne mint pas.

1. Exactitude métrologique
