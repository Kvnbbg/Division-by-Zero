# Portes de fortune — décisions d’investissement

On n’augmente les dépenses que si la porte précédente est verte.

| Porte | Condition | Action autorisée |
|---|---|---|
| G1 Exactitude | DivisionRuleService + tests statut | publier la démo |
| G2 Preuve d’attention | 4 semaines de contenus sans claim physique abusif | ouvrir newsletter |
| G3 Preuve d’achat | 10 commandes avec marge connue | second SKU |
| G4 Preuve de rachat | ≥ 15 % de réachat 30 j ou abonnés actifs | bundle |
| G5 Preuve d’économie | sinks ≥ 60 % du Gold émis sur 30 j | augmenter XP |
| G6 Atelier | contribution mensuelle > coûts outils | agent Spring + GraphQL dashboard |

Si une porte redevient rouge, on gèle le palier supérieur. C’est le mécanisme anti-illusion de fortune.
